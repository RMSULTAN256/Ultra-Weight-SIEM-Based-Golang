Zero-Trust Engine Architecture (NIST SP 800-207)

Continuous Verification: Every inbound packet and agent heartbeat is verified against baseline Sigma anomaly thresholds.

Policy Decision Point (PDP): Center SIEM analyzes the sliding window correlation state across nodes in memory.

Policy Enforcement Point (PEP): When a source IP exceeds brute-force thresholds (T1110) or network scanning rate (T1595), the SIEM issues a localized iptables -I INPUT -s <IP> -j DROP rule.

Resource Optimization: In-kernel packet dropping prevents resource starvation on servers with 1-2 GB RAM, keeping CPU footprint minimal.
