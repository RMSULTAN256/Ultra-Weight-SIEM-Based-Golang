DIAGRAM 1: Algoritma In-Memory Sliding Window Buffer vs Fixed Window

Rujukan: Jurnal 2 (SSHafe / Mitra et al., arXiv 2026) & Jurnal 1 (MDPI Sensors 2024)
Korelasi Stateful

Mekanisme Pemangkasan (Pruning)

Setiap event baru masuk dari IP yang sama, sistem melakukan sanitasi waktu: menghapus stempel waktu yang lebih tua dari $\Delta t$ ($5\text{ menit}$) secara in-memory sebelum memeriksa ambang batas (*threshold*).

Struktur Data Golang

Diimplementasikan menggunakan sync.Map dengan kunci berupa Source IP dan nilai berupa slice berurutan []time.Time. Operasi append dan filter dilakukan tanpa alokasi memori heap baru.

Kontribusi ke Bab 2 & 3 TA

Membuktikan keunggulan matematis sliding window terhadap serangan bursty maupun low-and-slow dibanding SIEM konvensional berbasis polling SQL.

DIAGRAM 2: Standalone Sigma Rule Parser & Formula Risk-Based Alerting (RBA)

Rujukan: Jurnal 4 (AutoSigma, arXiv 2026) & Jurnal 13 (Fraunhofer FKIE / Uetz et al., arXiv 2026)
Engine Evaluator

Kepatuhan Standar Sigma HQ

Aturan deteksi tidak ditulis menggunakan format query buatan sendiri, melainkan mematuhi spesifikasi open-source Sigma HQ sehingga aturan yang dibuat analis dapat diimpor langsung tanpa modifikasi kode.

Integrasi 5 Hipotesis Risiko (RBA)

Menghitung bobot skor risiko gabungan untuk mencegah alert fatigue. Alert yang berasal dari Datacenter Hosting dan sering gagal akan mendapat eskalasi prioritas otomatis (AUROC 0.92 merujuk Jurnal 13).

Zero External Dependency

Dieksekusi langsung oleh pustaka gopkg.in/yaml.v3 di dalam binary Golang tanpa butuh mesin kompilasi Python pySigma yang lambat.

DIAGRAM 3: Upstream Threat Intel Enrichment & Multi-Node Telemetry Stitching

Rujukan: Jurnal 5 (IEEE TIFS 2024 / Deidda 2026) & Jurnal 9 (Eckhoff et al., ISC 2025)
Enrichment & Graph

Keunggulan Upstream vs Post-Ingest

Memperkaya event di memori sebelum korelasi memangkas Mean Time to Detect (MTTD) hingga 40% (Jurnal 5) karena rule engine langsung memiliki konteks reputasi tanpa perlu query join di basis data.

Korelasi Lintas Node Berbasis Entitas

Mengadopsi konsep Timeline-Defining Properties ($\tau$) dari Jurnal 9: menghubungkan aktivitas penyerang yang mencoba login di Server 1 lalu mencoba exploit di Server 2 berdasarkan entitas IP yang sama.

Caching Kinerja Tinggi

Modul services/ipapi.go menyimpan hasil lookup di sync.Map lokal, mencegah bottleneck rate-limit API publik saat menerima aliran log ribuan EPS.

DIAGRAM 4: Siklus Tertutup Respon Insiden Otomatis (Closed-Loop SOAR)

Rujukan: NIST SP 800-61 Rev. 2 (Incident Response Lifecycle) & Jurnal 14 (Johnson & Nyberg, 2024)
Mitigasi Aktif

Sesuai NIST SP 800-61 Rev. 2

Menerapkan siklus standar respons insiden secara otonom: deteksi dini, isolasi penyerang (containment), pencatatan barang bukti, dan penutupan siklus tanpa jeda tunggu manual analis.

Respon Deterministik vs Black-Box

Mengatasi celah Jurnal 14 (di mana model RL rawan blast radius salah blokir). Pada sistem Anda, perintah blokir bersifat deterministik: hanya mengeksekusi DROP terhadap IP penyerang yang terbukti melanggar Sigma threshold.

Eksekusi Kernel Bridge

Aturan firewall diterapkan pada level antarmuka kernel Linux (iptables) container target, sehingga paket serangan berikutnya dibuang seketika sebelum membebani aplikasi web.

DIAGRAM 5: Topologi Deployment Fisik & Alokasi Port Container Docker

Rujukan: docker-compose.yml, implementation_plan.md, & Lingkungan Host Windows 10
Topologi Deployment

Konfigurasi Isolasi Jaringan

Semua container berkomunikasi via subnet private 172.20.0.0/16. Tidak ada dependensi ke jaringan luar selain akses berkala ke ip-api.com untuk pengayaan CTI.

Mounting Docker Socket untuk Mitigasi

Container siem-central dapat mem-mount /var/run/docker.sock sehingga binary Go di pusat SIEM dapat mengeksekusi perintah iptables di dalam container target secara instan saat mitigasi otomatis dipicu.

Port Forwarding ke Host Analis

Port 4000:4000 di-forward ke localhost Windows 10, memungkinkan analis membuka dasbor pemantauan di http://localhost:4000/dashboard dari peramban apa saja.
