3. IN-MEMORY SLIDING WINDOW ENGINE

Inti algoritma korelasi stateful temporal. Mencegah lolosnya serangan brute-force di batas blok interval waktu:

  • Menyimpan antrean stempel waktu []time.Time per identifier IP di memori.
  • Setiap event baru masuk pada waktu $T$, sistem memangkas stempel waktu yang < $(T - 5\text{ menit})$.
  • Jika jumlah event tersisa $\ge 5$, status korelasi terpenuhi (*Threshold Exceeded*).
